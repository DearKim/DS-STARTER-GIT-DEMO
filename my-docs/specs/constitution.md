# Constitution

## Project

- Name: Airbnb clone
- In one sentence: A travel accommodation booking platform

## Audience

- Main users: Both travelers and hosts
- What they want to do: Search and book stays

## Principles

1. Design principles come from the Figma file and Storybook components.

## Kit rules

These come from the starter kit. Don't change them.

- Build pages from the kit's parts: unchanged starter parts, or parts you changed and checked with `pnpm ds:review`.
- Use only design tokens from Figma. No made-up colors, sizes or fonts.
- Never invent facts. If something is missing, ask.
